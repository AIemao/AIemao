## 🤖 IA aplicada à Engenharia de Software

Construo e aprimoro agentes de IA, skills e instruções versionadas para apoiar investigação técnica, compreensão de código existente e validação de mudanças.

Uso diferentes tipos de agente conforme o contexto do problema: investigação, projeto, bug, documentação e testes. Cada tipo tem responsabilidades e limites próprios.

O custo de tokens é uma restrição constante no dia a dia. Por isso, estou evoluindo a organização das skills para um fluxo experimental de desenvolvimento assistido por agentes, inspirado em SDD e organizado com Kanban. O foco está em modularizar o contexto, reduzir o consumo desnecessário de tokens e tornar as etapas de trabalho mais rastreáveis e verificáveis.

Também desenvolvo integrações via MCP para conectar ferramentas e fontes de informação em fluxos de investigação técnica.

Em projetos de estudo, trabalho com RAG sobre documentação técnica de domínio público, avaliando estratégias de recuperação e a relevância dos resultados.

**Ferramentas de uso frequente:** Claude, GitHub Copilot
**Ferramentas exploradas:** ChatGPT, Codex e CodeRabbit
